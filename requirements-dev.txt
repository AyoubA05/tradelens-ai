# Dev / test / lint dependencies.
#   pip install -r requirements-dev.txt   (also installs the runtime deps)
# The deployed app installs ONLY requirements.txt; the API image installs ONLY
# requirements-api.txt.
-r requirements.txt

# The API surface's packages are listed individually rather than via
# `-r requirements-api.txt`, and that is deliberate.
#
# The test suite imports BOTH surfaces: Streamlit AppTest for the UI and
# FastAPI's TestClient for the API. Streamlit 1.50 requires pillow<12, while
# requirements-api.txt pins pillow 12.3.0 on Python 3.10+ to stay off a
# known-vulnerable line in the container that decodes untrusted uploads.
# Including that file here would put both pins in one resolution and make the
# development environment unsatisfiable on the deploy interpreter.
#
# So development and CI test against pillow 11.3.0 (Streamlit's ceiling) while
# the API image runs 12.3.0. tests/test_requirements.py asserts this list stays
# in step with requirements-api.txt so the duplication cannot drift silently.
# Mirrors requirements-api.txt's interpreter split on purpose: CI runs 3.11 and
# must exercise the same FastAPI/Starlette the container ships, not an older
# pair that happens to install on the local 3.9 machine.
fastapi==0.120.4; python_version < "3.10"
fastapi==0.141.1; python_version >= "3.10"
starlette==1.6.0; python_version >= "3.10"
